# Interpreting results

Use medians and dispersion together. A single fastest run is not a publication result.

For each metric report the number of repetitions, median, mean, sample standard deviation, coefficient of variation, minimum, maximum, and confidence interval when available.

Do not silently remove outliers. If a run is invalid because of an infrastructure failure, retain it in the evidence and explain the exclusion rule explicitly.

A comparator result is meaningful only inside its semantic class and declared durability/configuration profile.
